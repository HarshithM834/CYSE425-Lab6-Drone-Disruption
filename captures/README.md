# Packet capture
The user-supplied file is Tello_Deauth_Attack.pcapng (31,688,896 bytes; 112,022 captured packet records).

It is not yet present on GitHub because the connected upload workflow rejected transferring the full PCAPNG file. The original is included in the downloadable repository package. To publish it, place that file in this folder and push a Git commit locally. Be mindful that the recording contains traffic from unrelated nearby devices.
